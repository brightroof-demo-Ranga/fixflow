# BrightRoof workshop notes — 14 October 2026

Answers from BrightRoof to the clarifying questions. Used as input for `/expand-request` Phase 2.

| Question | Customer's answer |
| --- | --- |
| What is a critical fault? | System produces zero output, or any safety sign: smoke, burning smell, sparks, exposed wiring |
| What does "respond within 24 hours" mean? | A technician is on site, or has completed a remote diagnosis, within 24 hours of the request |
| Do customers need accounts? | No. They identify with phone number + system ID and get a tracking link |
| Does WhatsApp stay? | Yes for now. Dispatchers enter WhatsApp and phone requests on the customer's behalf |
| How are customers notified? | SMS is a must; email is nice to have |
| Languages? | English first; Sinhala and Tamil in phase 2 |
| Go-live? | Pilot on 1 December 2026 with 3 technicians, all 12 by mid-January |
| Reporting? | Open jobs, SLA breaches, average time to resolve, jobs per technician per week |
